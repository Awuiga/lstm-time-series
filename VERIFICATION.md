# Проверка публикации

21 ноября 2026 года выполнены следующие проверки отдельно от рабочего проекта:

- Все 3650 записей локального CSV совпали с указанным зеркалом источника после чтения через pandas. Пропущенных значений и повторных дат нет; найдены два разрыва ежедневной последовательности.
- Исходный `check_point.pt` успешно загружен с `weights_only=True`. Mean/std совпали с параметрами, рассчитанными по первым 70% ряда. Строго загружены все веса модели из 67 201 параметра.
- `evaluate.py` оценил именно исходные пользовательские веса: validation RMSE `2.2985725390446645`, MAE `1.831433805707287`; test RMSE `2.236376295735538`, MAE `1.7404601972537426`. Baseline на тех же test-целях: RMSE `2.5953031529280843`, MAE `2.048262548262548`.
- `predict.py` выполнен с исходным checkpoint; прогноз следующего наблюдения `13.1934326743078 °C`. Он не проверяется по будущему факту, отсутствующему в файле.
- В отдельной копии полностью выполнен пользовательский `train.py`: 30 эпох, validation, выбор лучших весов, test, сохранение графика и полного checkpoint. Использован Matplotlib backend Agg для завершения без графического окна. В этом отдельном запуске test RMSE `2.2291`, MAE `1.7331`; в README публикуются метрики исходных весов, а не нового прогона.
- График README перестроен по исходному checkpoint и просмотрен. Он показывает 100 первых целевых test-наблюдений, а не рекурсивный прогноз.
- Проверены синтаксис и неизменность структуры вычислений двух пользовательских скриптов. Удалены только лишние пробелы в концах строк.
- Хеши исходных скриптов, CSV, обоих файлов весов и исходных PNG до и после работы совпали. Соседние проекты не редактировались. В исходной папке Git-истории не было.

Окружение: Windows, Python 3.13.2, PyTorch 2.10.0+cu126, pandas 3.1.1, NumPy 2.5.4, Matplotlib 3.11.2. CUDA доступна.

Исходная инициализация не фиксирована, повторное обучение не гарантирует те же результаты. Подбор настроек по test не выполнялся. Установка в полностью чистое окружение отдельно не проверялась. Данные, веса и рабочие логи не публикуются.
